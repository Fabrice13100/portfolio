## À propos

Je suis **Fabrice Parriaux**, technicien multimédia.  
Ce site regroupe une sélection de mes réalisations dans trois domaines :

- **Créations numériques**  
  Graphisme, modélisation 3D, motion design et montage vidéo  
  (Adobe Illustrator, Animate, Premiere Pro, SketchUp, InDesign…)

- **Développement Web**  
  Sites WordPress, applications interactives (Three.js), formulaires PHP/MySQL, prototypes Figma

- **Photographie**  
  Spécialisé dans les paysages et la nature du Haut-Doubs  
  Collaborations avec le Comité Départemental du Tourisme du Doubs et des sociétés de production
